## 사용자가 실제 사이트에서 해 보는 중 (결과 아직 없음)

숨은 방의 테스트 항목: 4층 (42, 15)를 밟기 전에는 그 오른쪽 빈 곳으로 못 가는지, 밟으면 문구가 크게 뜨고 방이 서서히 나타나 들어갈 수 있는지, 이불, 스탠드, 밥상, 화분 칸은 막히는지, 엘리베이터에 갔다 오면 다시 숨는지, 방 안에서 새로고침하면 방이 열린 채 시작하는지, (42, 15)에는 블록이 안 놓이는지, 휴대폰에서 문구가 잘리지 않는지, 레벨 업을 두 번 해도 레벨 글씨가 매번 반짝이는지.

경험치 변경의 테스트 항목: 접속하면 Lv.1과 레벨 밑 파란 경험치 막대 "EXP 0 / 100"이 보이는지, 캘 때마다 "경험치 +15"(채집장) 같은 알림과 함께 막대가 차는지, 100을 넘기면 "레벨 업!" 알림과 Lv.2, "EXP ○ / 200"이 되는지, 새로고침해도 경험치가 남는지, 작업장에서 상대를 쓰러뜨리면 경험치 100이 붙는지, 명예의 전당과 TOP 10이 새 레벨로 보이는지.
