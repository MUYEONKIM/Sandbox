## 사용자가 아직 정하지 않은 것

- 증권거래소 차익 막기: 가격이 정각에만 바뀌어 실제 시세를 보고 정각 직전에 사서 직후에 팔 수 있다고 알렸다. 막으려면 수수료나 정각 전후 거래 금지를 넣는다(지금은 수수료 없음).

- 휴대폰에서 아직 안 되는 조작(블록, 점프, 달리기, 작업, 인벤토리, 채팅)을 어떻게 할지. 휴대폰 화면에서는 키 안내, 미니맵, 랭킹 패널이 위쪽 절반을 가린다.

- 엘리베이터 안에서 공격을 막을지(지금은 쓸 수 있고, 막으려면 SQL `hit_player`도 바꿔야 함).
- 9층, 2·3·5·6층의 쓰임(지금은 못 감).
